# Chartroom

A self-hosted, open-source virtual tabletop for RPGs and miniature wargames, where every game is a ruleset package and AI can sit at the table.

- One engine for 5e, homebrew RPGs, and wargames from ancients to grimdark sci-fi
- A continuous, measured table, with optional square and hex grids
- Rules as data plus sandboxed Starlark scripts, with server-side dice and a replayable event log
- AI co-GMs, NPCs, and opponents through MCP, with every ruling logged
- Homebrew rules tested by simulated games before they reach the table

**Status:** early design. See [`docs/DESIGN.md`](docs/DESIGN.md).
