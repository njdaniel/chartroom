# Rulesets

Ruleset packages live here, one directory per package. The package format is defined by an M1 ADR; there are no packages yet.

## License

Everything under `rulesets/` is licensed under [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/) unless a file says otherwise.

- Content derived from the 5e System Reference Document carries the SRD's required attribution.
- Content derived from LANDWAR must stay CC-BY-SA 4.0 and be marked as such.
- Public-domain content (such as H. G. Wells's *Little Wars*) says so in its package manifest.
- No proprietary rules content is ever committed here.
